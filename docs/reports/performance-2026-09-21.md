# 性能分析与优化验证（2026-09-21）

## 结论

原始快照约 46 FPS，主要瓶颈是角色姿态同步和渲染，而非战斗逻辑。完成本次优化后，本机浏览器的 **1920×1080 实际渲染画布**在预热后的连续攻击采样中恢复到约 60 FPS。没有降低模型 LOD、贴图分辨率、抗锯齿设置、阴影分辨率、布料更新频率或特效强度。

这是本机、当前配置的实测结果，并非所有设备/分辨率下每一帧都不超时的保证。首次着色器编译、窗口尺寸变化和系统调度仍可能产生尖峰。原始快照没有 GPU 时间戳；下面的渲染耗时表示 CPU 提交用时，不能当成 GPU 执行时间。

## 定位与修改

1. **脚底检测和骨骼查找。** 本机细分测量中，双角色脚底检测约 5.4–6.4 ms。原实现逐帧遍历所有骨骼，并对每根骨骼重复刷新父级路径。现在缓存实际接触骨骼，只更新这些骨骼；手臂、小腿查找也缓存，重装模型时清空。测得脚底检测约 0.10–0.16 ms。
2. **重复骨骼矩阵。** 每个角色 21 个网格各持有一份相同的 679 根骨骼数据。安装角色后，仅在骨骼对象、顺序、逆绑定矩阵完全相同时共享 Skeleton，保留每个网格自己的 bindMatrix。实际从每角色 21 份变为 1 份，减少矩阵计算、复制和 GPU 上传。不同角色、不一致的绑定和不同骨骼顺序不会被合并。
3. **重复场景更新。** 背景、后排角色、前排角色仍按原顺序绘制，但每组分层绘制只刷新一次世界矩阵；异常时也恢复状态。运动模糊复用已解析的姿态，并跳过不属于当前角色层的根节点。
4. **特效材质反复失效。** 序列帧更换贴图不再逐帧标记材质程序失效；编辑器修改仍即时应用。已用材质进入有上限的池，在连续命中间复用，避免每次销毁后重新建立渲染资源。迟到的贴图回调不会修改已结束的特效。
5. **首次贴图上传。** 可播放的序列帧贴图提前到加载阶段上传，每 16 张让出一次执行机会。仍保留原始贴图质量；代价是加载阶段多承担上传工作。
6. **高清下的着色器浪费。** 命中阴影原来对每个像素计算 4 个槽位 × 16 条预留光束，再将未启用项乘零。现在跳过强度为零的槽位和未启用光束；默认单次、6 光束命中从最多 64 组光束计算降为 6 组。冲击波和辉光同样跳过零强度槽位。有效项的公式、混合顺序与强度保持原样。
7. **监控开销。** 性能快照继续逐帧采样、保存；监控文字和图表按配置的刷新间隔绘制，不再逐帧重复更新 DOM/canvas。

## 回归与构建

- 增加骨骼共享前后变形一致性、不同绑定隔离、脚底检测、矩阵更新次数、异常恢复、材质不重复失效、编辑器更新、材质池独占性检查。
- 最终使用两个测试 worker 运行全量回归，126 个测试文件、819 个用例全部通过。此前高并发运行时有一个旧烟环测试超过 5 秒超时，未放宽超时阈值。
- 浏览器检查了角色显示、移动/跳跃/攻击与命中特效；测试页面未出现浏览器错误日志。
- Vite 生产资源打包通过。
- `npm run build` 的完整流程仍被项目原有 TypeScript 错误阻挡，包括 AnimCrossfade 的收窄比较、ControlPanelHooks 返回类型、LightSelective 类型和若干旧测试类型。已用 HEAD 的独立源码副本对照，剩余错误没有新增错误消息。本次未扩展修改这些无关模块。

建议在用户日常使用的浏览器、原配置和分辨率下再次导出性能环形快照，重点观察首次命中、持续多次命中、画中画和更高分辨率。若仍掉帧，下一步应打开 GPU 时间戳，把 GPU 像素开销与浏览器调度分别测量，而不是继续降低角色画质。


## 后续修复：受击阴影跳帧

地面投影和角色自阴影共用的阴影贴图，原来只按动作阶段、动画重启序号和量化后的角色位置判断是否更新。受击、停顿中的慢动作以及待机骨骼动画都可能在这些值不变时继续改变姿态，造成阴影停住后跳动。

现在在每次完整画面呈现前请求一次阴影更新，删除上述粗粒度缓存；分层绘制和画中画仍复用本帧阴影。保留原阴影分辨率、滤波、光照和动画设置。

验证：在 1920×1080 浏览器中临时记录角色网格的实际阴影绘制回调并连续攻击。一个 240 帧窗口包含 148 个受击帧，全部逐帧更新阴影，每帧恰好绘制一次，没有漏帧或分层重复绘制。自动测试结束后的两个窗口 CPU 平均 11.83 / 12.61 ms，P95 为 15.5 / 17.2 ms，平均呈现间隔 17.44 / 17.19 ms（约 57–58 FPS）；恢复完整阴影更新增加了开销，不能将前文优化前的阴影更新策略下测得的约 60 FPS 直接视为本次修复后的保证。与自动测试同时运行的采样受到 CPU 竞争影响，未用于该性能结论。

渲染回归 41 个文件、331 个用例通过；测试用自动输入与计数代码已移除。
