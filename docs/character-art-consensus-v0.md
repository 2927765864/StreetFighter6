## 4. 贴图类型含义（✅ · 2026-08-14 本机验证）

验证样例：衣服 A / 头 / 身 / 发 的颜色、nrrc、atos、cmask。

| 类型（文件名特征） | 含义 | 网页用法 |
|--------------------|------|----------|
| **颜色**（`albd`） | 表面颜色；衣服/发偏中性灰，头/身有肤色 | → 颜色贴图；布/发需预染 |
| **凹凸打包**（`nrrc`） | 红绿为方向，蓝近满，A 含粗糙类信息；**非**标准三色凹凸 | **必须转换** → 标准凹凸 + 粗糙灰图 |
| **atos** | 多通道打包；衣服有结构，身体近常数 | **拆开，有用才挂**（优先 AO） |
| **染色遮罩**（`cmask`） | 分区，非外观本身；头 cmask 很弱 | **预染进最终颜色**，不单独当颜色贴 |

网上 RE 改模资料（如 RE 贴图类型讨论、Nexus Texture Packer、RE Mesh Editor changelog）仅作辅助；**以本机图为准**。

## 7. 凹凸转换（P4 · ✅）

| 项 | 共识 |
|----|------|
| 输入 | 本次范围内全部相关 `*nrrc*`（主 + 细节） |
| 输出 | `{part}_bump.png`（标准切线空间三色）、`{part}_rough.png`（来自 A 通道） |
| 算法原则 | R,G → 方向 X,Y；重建 Z；写回 0–1 RGB；A → 粗糙灰图 |
| Y 翻转 | 默认 **不翻转**；角色上整体反了则 **全局** 翻转重出，禁止单 mesh 乱改 |
| 执行 | Python 批量；Blender 只做挂接预览 |

| 材质关键词 | 贴图包 |
|------------|--------|
| Head00、Mouth00 | **head** |
| Body00 | **body** |
| Eye00 | **eye** |

| Costume00、Threads、Ring、Obi、ObiSign | **clotha** |

细节 nrrc（bodydetail、blend、bdm、fdm）并入 **body** 或 **head**，不另开运行时第八套槽。
