## 1. 一句话（✅）

隆现有腰带保持造型长度；**环绕腰部的主体固定**，**垂下带尾**用与头巾同路径的物理做出甩尾与回弹，跟随移动、跳跃与出招；默认手感比头巾**更硬、更短**；尽量少钻进大腿/髋；**受击定住与受击硬直期间带尾仍继续动**；参数在调试面板可调，并保存进配置。**不做**专门的静止呼吸微晃；**不规定**「移动/跳跃优先于攻击」的落地顺序。

## 2. 现状前提（✅）

| 项 | 共识 |
|----|------|
| **当前形态** | 腰带是角色上的**静态装饰**（含环腰与垂下部分），不是已有独立带尾动画件 |
| **造型长度** | **先按现有模型长度**，不特意加长或改成戏剧化长带 |
| **可动区** | **只有垂下带尾**动；环绕腰部绑住部分**完全固定** |

## 3. 要做什么（✅）

### 3.1 观感目标

- 目标是**跟手头巾同款路径的物理带尾**：急停、变向、起跳、落地、出招时有可见甩尾与回弹，不是「几乎看不出在动」。
- 相对头巾的手感偏好：**更硬、更短（摆幅更小、回弹更快）**——更像厚皮带尾，而不是布飘带；乱飞不可接受为默认。
- **不做**专门的静止「呼吸感」微晃要求；站立不动时允许几乎静止或仅有惯性残余，不以此为验收项。

### 3.2 动作跟随

- 移动、跳跃、攻击时带尾都应有可见物理反馈。
- **不规定**「移动/跳跃优先于攻击」的验收优先级；三类动作都要跟手即可，不因攻击反馈稍弱而单独判失败（仍须有可见跟随，不是完全冻死）。

### 3.3 时间豁免（不受卡顿拖死）

| 情况 | 共识 |
|------|------|
| **受击定住**（命中卡顿、角色身体定住的那一瞬） | 腰带带尾**继续飘**，不跟身体一起冻住 |
| **受击硬直**（被打后不能操作的那段） | 腰带带尾**整段继续动** |
| **慢动作 / 暂停 / 回放** | ⬜ 尚未形成共识（第一版可不做特殊策略，待另定；与头巾同口径） |

### 3.4 防穿模

- 观感要**比较干净，少穿模**。
- 碰撞范围：**主要跟角色自己的大腿 / 髋**防穿；第一版不以头肩为主目标。
- **不管场景**（地面、墙壁、道具第一版不做）。

### 3.5 实现路径与调节存档

- **复用头巾的代码路径**（同一套二次运动/弹簧链实现），腰带挂自己的挂点与碰撞，**不要**为腰带另起一套布料引擎。
- 腰带须有**独立开关与独立参数**（刚度、阻尼、重力、碰撞半径等可感项），默认相对头巾更硬更短；**不得**与头巾强制共用同一组数值。
- **调试面板**提供实时调节。
- 调好后能**保存成配置**，下次启动仍在（与现有本地默认 / shipping 预设习惯一致）。

### 3.6 算不算必须做成

- **算。** 写进本文件的观感、豁免、防穿模与可调可存，就是要实现的完整目标，不是可有可无的装饰。
- 允许第一版用看得见的简化碰撞或简化链结构推进；**不允许**用「整条腰带跟着腰骨转一下」或「完全冻在受击定住里」冒充已做成。

## 4. 不做什么（✅）

| 不做 | 说明 |
|------|------|
| 加长/重做腰带造型 | 第一版不改成长飘带或夸张垂尾 |
| 环腰主体参与大变形 | 环绕腰部部分保持完全固定 |
| 静止呼吸感微晃 | 本版明确不做专门呼吸/微风验收 |
| 「移动/跳跃优先于攻击」排序 | 本版不规定该优先级 |
| 其他角色腰带物理 | 只做隆 |
| 通用布料引擎全家桶 | 复用头巾路径即可，不为「以后所有布料」另铺大系统 |
| 场景碰撞（地/墙等） | 第一版不做 |
| 以软飘、大甩为默认 | 默认比头巾更硬更短；夸张飘法若需要，用参数拧，不当默认成功标准 |
| 与头巾共用同一组参数 | 可共用代码路径，参数必须独立 |
| 把头巾调查文档里的算法当已定案 | 技术选型以执行方案为准；调查仅供参考 |

---

## 5. 验收时怎么看（✅）

| 项 | 怎样算过 |
|----|----------|
| **移动** | 跑、急停、变向时带尾有可见甩尾与回弹，且不明显钻大腿/髋 |
| **跳跃** | 起跳、滞空、落地有可见物理反馈 |
| **攻击** | 出招/收招有跟随甩动（须可见，不要求强于移动/跳跃） |
| **静止** | **不要求**呼吸微晃；不僵成「整条跟着腰死绑」即可 |
| **受击定住** | 身体定住时带尾仍在动 |
| **受击硬直** | 硬直全程带尾仍在动 |
| **造型** | 仍是现有长度；环腰固定、仅带尾动 |
| **手感默认** | 比头巾更硬、更短；可用面板拧 |
| **参数独立性** | 调腰带不影响头巾默认手感；两边可分别开关 |
| **存档** | 面板改参后能保存，重开仍在 |
| **范围** | 仅隆；场景碰撞未做不算失败 |
