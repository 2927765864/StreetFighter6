## 0. 一句话

在现有体素烟「烟团外形」外壳内，可开关一种初始成团方式：**缕烟**——烟不再以整团棉花式填满外壳，而是由多条可弯、可粗可细的连续烟绳排布而成；绳与绳有间隔，整体轮廓仍像所选烟团形状。

---

## 1. 开关与兼容（✅）

| 项 | 锁定 |
|----|------|
| **开关** | 独立「缕烟」开关。关闭时行为与**今天**完全一致（整团棉花式填充）。 |
| **关闭时参数** | 缕烟相关参数可保留在配方里，但**不生效**。 |
| **旧配方** | 无缕烟字段时视为关闭；加载后自动补默认值，不得报错、不得改变旧观感。 |
| **现有外形** | 球 / 盘 / 环 / 弧 / 箭 / 柱 **继续作为外壳范围**；缕烟只出现在该范围内（受边缘软硬约束）。外形相关现有参数照旧有用。 |

---

## 2. 视觉目标（✅）

| 项 | 锁定 |
|----|------|
| **关缕烟** | 外形内随机/高斯整团，像一团挤在一起的棉花。 |
| **开缕烟** | 外形内是一缕一缕的**连续粗绳**（肉眼应看成完整烟绳，不要明显一颗颗豆子）。 |
| **排布** | 顺着烟团外形本身的走向（环沿环、弧沿弧、箭沿臂等）；球形由实现给好用默认，再用参数拧。 |
| **疏密** | 既能铺满轮廓，也能稀疏几条；靠条数、间隔等参数调节。 |
| **缝隙** | 刚出现时能看出一条一条；缝里淡烟量**可调**（见 §3）。 |
| **之后的流体** | 缕烟只改**初始出现在哪**；命中密度、冲击、浮力、湍流等**仍管整体浓淡与推烟**，语义不变。 |

---

## 3. 每缕长什么样（✅）

| 项 | 锁定 |
|----|------|
| **长度** | 可长可短；有基准值，再带随机。 |
| **粗细** | 有基准值，再带随机。 |
| **粗细样式** | 同一团里三种混着随机出现：**大致均匀** / **一头尖（圆锥）** / **中间粗两头细**。 |
| **弯曲** | 有「弯曲强度」参数：几乎直到明显很弯；每缕再带一点乱。 |
| **连续性** | 看起来像连续粗绳，不是疏落的粒子串。 |

---

## 4. 可调参数（✅）

面板在「烟团形状 / 命中泼溅」附近单独一块 **「缕烟」**。总开关打开后展开：

| 参数（白话） | 作用 |
|--------------|------|
| **缕烟开关** | 开/关 |
| **条数** | 大约多少缕（见 §5：可被总随机晃一点） |
| **每缕长度** | 绳子有多长（相对烟团大小） |
| **每缕粗细** | 绳子有多粗（相对烟团大小） |
| **缕与缕间隔** | 绳子之间留多大空 |
| **整体旋转 / 主朝向** | 这一捆相对外形默认走向再转多少 |
| **各缕角度随机幅度** | 每根相对主方向能歪多少 |
| **弯曲强度** | 弯多少 |
| **外形边缘软硬** | 绳子必须裁在外形里，还是允许稍微探出 |
| **缝里淡烟** | 0 = 缝尽量空；越大缝/绳旁淡烟越多 |
| **缕烟总随机强度** | 放大或缩小缕相关乱量（与现有「随机种子 / 随机幅度」配合；同一种子可重放） |

以上均须一次做完进编辑器；无「第一版只做一半参数」。

---

## 5. 对话收尾三点（✅ 已选定）

此前「都可以」的三点，锁定为：

| 项 | 选定 |
|----|------|
| **条数** | **大约 N 条**：以条数基准为准，再被**缕烟总随机强度**轻微增减（不是永远死锁整数且零随机）。 |
| **缝里淡烟** | **在绳子附近晕开**（绳旁一圈淡烟），不是整壳均匀铺一层薄雾。 |
| **边缘软硬** | **默认允许轻微探出外壳**；用「外形边缘软硬」可拧到更硬（严格裁在外形内）或更软（探出更多）。 |

---

## 6. 编辑器预览（✅）

| 项 | 锁定 |
|----|------|
| **预览** | 打开显示烟团形状时，附带**简单**缕排布示意（几根曲线即可），不必与最终体素密度完全一致。 |
| **不必** | 高精度体积预览、逐像素对齐。 |

---

## 7. 不做（✅）

| 不做 | 说明 |
|------|------|
| 改成另一套流体求解器 | 仍用现有体素烟模拟 |
| 关掉缕烟后仍残留缕状初始 | 关 = 回到今日整团 |
| 用录像/序列帧冒充缕烟 | 必须是参数驱动的初始成团 |
| 把缕烟做成与现有外形无关的第二套外壳 | 外形仍是现有六种 |

---

## 8. 验收（✅）

1. 关缕烟：与改前同配方观感一致（允许浮点误差级差异）。  
2. 开缕烟：球/盘/环/弧/箭/柱下均能看出一缕一缕，且整体轮廓大致跟外形。  
3. 调条数、长度、粗细、间隔、弯曲、缝里淡烟、边缘软硬，肉眼可感。  
4. 锁随机种子重复播放，缕排布一致。  
5. 命中密度/冲击仍能改变浓淡与推动。  
6. 旧配方加载不炸、默认关缕烟。  
7. 编辑器有缕烟区块与简单预览线。
