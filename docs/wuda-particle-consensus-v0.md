## 1. 一句话（✅ · 🔒）

在训练场角色蒙皮表面上维持一层可调外观的附着粒子；粒子平时贴着皮肤随动画变形；当表面点速度或加速度超过阈值（含出拳急停、挥空顿挫）时，粒子脱离并带着脱落瞬间的速度飞出，再受重力与阻力等简化规则影响；运动幅度大的部位脱落更明显；粉尘/液体/气体差异仅通过参数区分，不另起互不相通的三套引擎。

## 3. 要做什么（✅ · 🔒）

### 3.1 涂层与跟踪

| 项 | 共识 |
|----|------|
| **覆盖** | 粒子分布在角色 **蒙皮网格表面**（薄涂层），不是只挂在少数骨骼挂点 |
| **跟动** | 粘着态粒子每帧跟随所附着的表面位置（随蒙皮变形） |
| **采样** | 初始分布按表面积大致均匀（允许密度参数）；允许按部位权重调节疏密 |

### 3.2 脱落规则（运动驱动）

| 项 | 共识 |
|----|------|
| **驱动量** | 至少使用表面点的 **速度**；并须能对 **加速度 / 急停**（速度骤降）敏感，使出拳打空或命中顿挫时能甩出 |
| **部位差异** | 同一套规则下，运动更猛的部位脱落数量或初速更强（可调） |
| **脱落初速** | 脱落瞬间粒子继承（或按系数继承）该表面点当时速度，再进入自由飞行 |
| **禁止主路径** | 不以「每招手写事件表触发固定喷发」作为 **唯一** 驱动；允许另加可选「强制抖落」调试开关，但主表现必须来自运动传感 |
| **可选脱落时机锁（2026-09-01）** | 开关「仅攻击发生帧可脱落」：打开后，只有当前逻辑帧存在攻击框时才允许脱落；**发生帧前后速度/加速度传感照常**，只锁「能否变成飞出」。发生帧 = `phase===attack` 且本帧 `currentHitBoxesLocal` 非空。默认关闭（与原先随时可脱落一致） |

### 3.3 自由飞行与外观

| 项 | 共识 |
|----|------|
| **简化物理** | 自由态至少有重力、线性阻力、寿命；允许简化，不要求粒子互碰、不要求完整流体 |
| **外观可换** | 同一套运动核心下，通过参数区分偏粉尘 / 偏液体 / 偏气体（大小、重力强弱、透明度、寿命等） |
| **消失** | 自由粒子主要靠寿命消失；不要求碰地弹开/积水（与打击汗珠共识同类简化） |

### 3.4 时间与顿帧

| 项 | 共识 |
|----|------|
| **时钟** | 涂层模拟使用 **墙钟时间**（与头巾物理同类）：命中顿帧导致逻辑/身体姿态停住时，已脱落粒子仍继续飞 |
| **新脱落** | 身体因顿帧定住、表面速度近零时，不应持续大量新脱落（由运动阈值自然保证） |

### 3.5 调试与存档

| 项 | 共识 |
|----|------|
| **可开关** | 总开关关闭后无涂层、无开销路径可接受为不更新 |
| **面板** | 关键阈值与外观参数必须进现有调试面板体系（`DebugGui` / `ControlPanel` 与 CONFIG 一致），并可进项目配置持久化 |
| **可视化** | 须提供调试显示：至少能看出粘着粒子位置或脱落事件量级（具体控件见执行方案） |

### 3.6 验收场景（隆）

下列均须能在训练场靠运动观察到（调参后），且不依赖单独写死「5LP 特效事件」：

1. 角色静止或缓动时，涂层大致贴身、不明显乱飞。  
2. 出拳 / 踢腿等高加速度或急停动作时，对应肢体附近有可见甩出。  
3. 调高重力 → 自由粒子更明显下坠；调低脱落阈值 → 更易甩出。  
4. 总开关关闭 → 涂层消失。

## 5. 怎样算做成（✅ · 🔒）

1. 隆身上有可开关的表面涂层，粘着态跟蒙皮。  
2. 运动阈值可调，出拳类动作能甩出，静止不无故狂喷。  
3. 自由态有重力/阻力/寿命，外观参数可区分尘/水/气倾向。  
4. 参数进调试面板与配置持久化。  
5. 与打击特效可同时开启而不互相顶替职责。  
6. 有自动化测试覆盖：采样绑定、速度差分、脱落状态切换、配置字段存在（具体用例在执行方案）。
