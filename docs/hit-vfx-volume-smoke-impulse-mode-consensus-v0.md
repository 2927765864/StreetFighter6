## 0. 一句话

体素烟受击冲击力可选两种清晰模式：**方向**（整体沿指定轴推）与 **四散**（以烟团中心向外炸开）；方向在烟盒本地空间可调，旧配方保持「跟受击方向」的观感。

---

## 1. 模式（✅）

| 模式 | 行为 |
|------|------|
| **方向 `direction`** | 烟团出现时，整体获得沿指定方向的推力（可再混少量径向/旋转，见现有旋钮）。 |
| **四散 `scatter`** | 以**形状中心**为原点，向四面八方发力（纯径向为主）。 |

坐标：**烟盒 / 物体本地 XYZ**（与体积网格轴一致）。预览台与训练场命中共用同一套配方语义。

---

## 2. 方向来源（仅方向模式）（✅）

| 来源 | 行为 |
|------|------|
| **受击 `hit`** | 冲击方向 = 本次命中法线变换到烟盒本地（**今日默认行为**）。 |
| **自定义 `custom`** | 冲击方向 = 配方里的本地向量 `impulseDir`（归一化后使用；零向量回退 +Y）。 |

外形朝向（球/盘/环等对齐受击）**仍用命中法线**，与冲击方向解耦。

---

## 3. 旧配方（✅）

| 项 | 锁定 |
|----|------|
| 无 `impulseMode` 字段 | 视为 `direction` + 方向来源 `hit`，观感与今天一致。 |
| 缺省补字段 | 加载后可写出默认值；不得报错。 |
| 新元素默认 | `direction` + `hit`（实战跟拳）；可在面板改成自定义本地方向或四散。 |

---

## 4. 编辑器（✅）

「溅射与种子」里冲击力附近：

- 模式下拉：方向 / 四散  
- 方向模式展开：方向来源（受击 / 自定义）、自定义时显示本地 XYZ +「显示冲击方向」箭头  
- 四散模式：隐藏方向来源与自定义向量；提示从中心向外  
- 保留：冲击力强度、旋转推力、子步、随盒子缩放；方向模式下保留「爆炸占比」作微调  

---

## 5. 不做（✅）

| 不做 | 说明 |
|------|------|
| 世界空间独立一套方向 | 本版只锁本地 XYZ |
| 按缕烟逐绳不同冲击 | 冲击仍是整团流体力 |
| 去掉压力投影 | 四散仍可能被不可压缩投影削弱（提示即可） |
