# 角色局部动态模糊

角色动作使用 Blur 项目第二套「清晰优先 · 局部模糊」的重建思路：当前与上一帧角色姿态均用当前相机投影，只取角色自身运动；保留原方案的 0.65 短拖影系数、八方向邻域搜索、中心清晰样本和随距离衰减的双向采样。角色骨骼与位移使用同一速度来源，前后角色按本项目的 2.5D 显示优先级处理遮挡。

移动（走、冲、跳）与攻击／受击继续分别使用 `moveScale`、`attackScale`。出厂预设保留移动 0.2、攻击／受击 1；震屏仍由镜头强度单独控制，设为 0 即为纯角色局部模糊。相机跟随不会计入角色速度。

控制面板 → 动态模糊：

| 参数 | 默认预设 | 作用 |
| --- | --- | --- |
| 移动强度 | 0.2 | 行走、冲刺、跳跃的模糊倍率 |
| 攻击／受击强度 | 1 | 出招与受击的模糊倍率 |
| 镜头强度 | 0.35 | 独立震屏位移与 FOV 模糊；0 关闭 |
| 最长拖尾 | 16 像素 | 从中心向单侧采样的最大距离 |
| 曝光时长 | 16.67 毫秒 | 按帧间时间归一化，增大时拖影加长；0 关闭模糊 |
| 主体清晰保留 | 0.75 | 原始中心像素的权重，越高越清楚 |
| 局部采样范围 | 13 像素 | 八方向搜索运动边缘的范围 |
| 最小运动阈值 | 0.5 像素 | 过滤曝光期内的微小运动 |
| 采样次数 | 24，最高 32 | 增大时拖影更连续，开销也增加 |

像素参数使用实际绘制分辨率。暂停逐帧会保留上一运动帧的速度，曝光、采样和清晰保留仍可即时调整。重新启用或改变窗口尺寸后重新建立姿态基准，避免旧帧拖影。

旧的历史画面匹配、分块速度扩散与旧合成代码已删除。旧预设的 `objectScale` 只在导入时迁移为移动／攻击强度，新配置不再保存该字段。

验证：局部模糊、深度捕获、骨骼缓存、震屏和逐帧保持的回归测试，以及浏览器 WebGPU 运行与控制面板检查。项目已有的无关 TypeScript 错误仍会阻止 `npm run build` 的类型检查阶段；单独 Vite 打包可通过。
