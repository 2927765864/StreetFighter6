## 1. 一句话（✅）

隆现有道服裤保持现有造型；**腰部绑住区域固定**，**大腿外侧到裤脚**做出偏软、宽松、有下垂感的布料物理；走路、急停、跳跃、踢腿、蹲起等动作都要有自然跟随；静止时有一点点呼吸感；**几乎不能钻进腿部**，并尽量少钻进腰带；**受击定住与受击硬直期间裤子仍继续动**；参数在调试面板可调，并保存进配置。对战与展示同一套效果。

## 3. 要做什么（✅）

### 3.1 观感目标

下列三项是**同一完成目标的组成部分**，不是互斥选项，也**不是**可分期砍掉的半成品：

1. **裤脚 / 下摆有明显晃动**：急停、变向、落地、踢腿后有可见甩动与回落。  
2. **大腿到小腿有整体布料感**：裤管不是铁皮贴腿；动作时有鼓起、延迟、回弹。  
3. **宽松下垂感**：偏软、有垂坠与惯性，像厚棉布道服裤，而不是硬壳或薄纱乱飞。

- 默认手感：**偏软、有下垂**。  
- 甩幅上限：**在几乎不穿腿的前提下，尽量做足宽松感**；不以「宁小勿乱」为借口把布感做没。  
- 站立不动时要有**一点点呼吸感**微晃，避免完全僵死；不要做成抢戏的大风。

### 3.2 动作跟随

下列动作都必须达到可见、自然的物理反馈（**不设「先做移动、攻击后补」的优先级砍刀**）：

- **地面移动**：走、跑、急停、变向  
- **跳跃**：起跳、滞空、落地  
- **踢腿类攻击**：出脚与收腿时裤管跟随明显  
- **蹲下 / 起身**：堆积、鼓起、回落要自然  
- **其他会带动下半身的动作**：同样不得冻成铁皮；验收以「该动作下半身在动时裤子也有合理反馈」为准

### 3.3 时间豁免（不受卡顿拖死）

| 情况 | 共识 |
|------|------|
| **受击定住**（命中卡顿、角色身体定住的那一瞬） | 裤子**继续动**，不跟身体一起冻住 |
| **受击硬直**（被打后不能操作的那段） | 裤子**整段继续动** |
| **慢动作 / 暂停 / 回放** | ⬜ 尚未形成共识（当前可不做特殊策略，待另定） |

### 3.4 防穿模

| 项 | 共识 |
|----|------|
| **腿部** | **硬底线**：几乎不能看到裤子钻进大腿或小腿。宁可在极限动作里收一点甩幅，也不能大面积穿腿 |
| **腰带** | **尽量少**钻进腰带/腰封区域；不是比腿更硬的底线，但交叠脏了要能拧参数或加约束改善 |
| **地面 / 墙壁 / 场景** | **本版不做**专门场景碰撞；裤脚埋地一点点若发生，不单独作为本文件失败项（仍可用别的手段顺带改善，但不锁定必须做地面防穿） |

### 3.5 独立设计与调节存档

- 裤子物理**独立设计**：不强制复用头巾/腰带代码路径，也不强制共用其参数表。  
- 须有**独立开关与独立参数**（软硬、下垂/重力感、晃动幅度、回弹、呼吸微晃、防穿约束一类可感项；具体字段名属实现，不在本共识钉死）。  
- **调试面板**提供实时调节。  
- 调好后能**保存成配置**，下次启动仍在（与现有本地默认 / shipping 预设习惯一致）。

### 3.6 算不算必须做成

- **算。** 写进本文件的观感三项、动作面、豁免、防穿腿、少穿腰带、可调可存，就是要实现的完整目标。  
- **不允许**用下列冒充已做成：  
  - 只让裤脚轻微晃一下、大腿仍像铁皮  
  - 只有延迟跟随、没有宽松下垂感  
  - 整条裤子跟着腿骨死绑、看不出布料惯性  
  - 完全冻在受击定住或受击硬直里  
  - 大面积穿进腿里仍称「过关」

## 4. 不做什么（✅）

| 不做 | 说明 |
|------|------|
| 加长/重做裤子造型 | 不改成夸张宽袍或额外加长裤脚造型为目标 |
| 腰部大变形 | 腰部绑住区域保持基本固定；不把整条裤子从腰开始扭成布袋 |
| 与头巾/腰带强制同路径 | 可借鉴经验，但本文件明确**独立设计**，不以「复用飘带链」为成功条件 |
| 其他角色裤子物理 | 只做隆 |
| 通用衣物系统全家桶 | 本文件只服务隆道服裤目标 |
| 场景碰撞（地/墙等）作硬验收 | 本版不锁必须做 |
| 展示专用另一套假物理 | 对战与展示同一套 |
| 分期半成品目标 | 禁止「先只做裤脚、以后再做整条布感」这类完成口径 |
| 默认乱飞抢戏 | 宽松要做足，但不能以挡招式轮廓、大面积穿模为代价 |

## 5. 验收时怎么看（✅）

| 项 | 怎样算过 |
|----|----------|
| **裤脚晃动** | 急停、落地、踢腿后下摆有可见甩动与回落 |
| **整条布料感** | 大腿到小腿在动作中有延迟、鼓起或回弹，不是贴腿铁皮 |
| **宽松下垂** | 默认偏软、有垂坠；在不穿腿前提下尽量做足 |
| **移动** | 走/跑/急停/变向有自然跟随 |
| **跳跃** | 起跳、滞空、落地有可见物理反馈 |
| **踢腿** | 出脚与收腿裤管跟随明显 |
| **蹲起** | 蹲下与起身时堆积/鼓起/回落自然 |
| **静止** | 有轻微呼吸感，不僵死、不抢戏 |
| **受击定住** | 身体定住时裤子仍在动 |
| **受击硬直** | 硬直全程裤子仍在动 |
| **防穿腿** | 几乎看不到钻进大腿/小腿 |
| **防穿腰带** | 尽量少钻进腰带；明显脏叠需能调好 |
| **可动区** | 腰固定；大腿外侧与裤脚在动 |
| **造型** | 仍是现有裤子造型，未靠加长造型混过关 |
| **独立性** | 有独立开关与参数；不依赖把头巾/腰带调坏才能出效果 |
| **存档** | 面板改参后能保存，重开仍在 |
| **范围** | 仅隆；未做地面碰撞不算本项失败 |
