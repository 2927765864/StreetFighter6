## 1. 一句话（✅）

在训练场对打与独立预览台里：打中人时用**规则驱动、可调参数、带轻微随机**的方式呈现火花、火花光照、附带小粒子、短促扬尘烟、受击甩出的汗珠；观感偏**写实物理感**（允许简化近似，不要求严格守恒）；用独立编辑台做元素增删、分组、专属参数、低速/逐帧、一键重放、锁随机种子，配方保存进**项目配置**；未格挡与格挡共用底座、配方可完全不同；特效时间轴与命中顿帧**分开可调**。

## 3. 要做什么（✅）

### 3.1 底座边界

| 项 | 共识 |
|----|------|
| **覆盖** | 只覆盖「**打中人**」时的画面反馈（含未格挡受击、格挡成功等打在人身上的反馈） |
| **不含** | 飞行道具本体、大招全屏、场景环境常驻特效等「非打中人」内容（不要求本次做成，也不要求本次验收） |
| **格挡与未格挡** | **同一底座**；允许两套（或多套）**配方**内容任意不同，不规定必须长得像 |

### 3.2 实现原则（物理化 / 程序化）

| 项 | 共识 |
|----|------|
| **底线** | **看起来像物理即可**：重力、速度、寿命、消散、亮度衰减等用规则驱动；允许简化近似 |
| **随机** | 实战解锁随机时，每次出现有**略可感知**的差别；调试可**锁定随机种子**，同一次重放结果一致 |
| **禁止主路径** | 不以整段逐帧精灵、短视频贴击中点、完全写死不可调、抄解包官方特效、或每招手搓不可复用套装作为主实现 |

### 3.3 必须具备的元素

下列元素均须可在编辑台中作为**一类元素**增删、调参、编组，并在打中人时能按配方触发：

| 元素 | 共识要点 |
|------|----------|
| **打击火花** | 击中瞬间的亮点/碎片式火花；有出现、消失、亮度、颜色、初始形状等**专属参数**；**短命火花光照参数内嵌在火花上**（亮度/距离/照角色/照同组特效等），**不作为树上可新建的独立元素** |
| **火花附带小粒子** | 火花周围碎屑/火星一类附属粒子 |
| **击中烟雾/扬尘** | **短促一股尘烟、很快散掉**（偏打击扬尘，不是大团久留烟） |
| **汗水飞溅** | **击中时从身体甩出的汗珠**；按液体相关物理参数运动；**只靠寿命消失**（不要求碰地弹开/摊开） |

每种元素有一套**专属参数**（具体字段名属实现，不在本共识钉死）；编辑台必须能改到可感差异。旧数据若仍含独立「火花光照」元素，加载时**自动并入**对应火花参数。

### 3.4 触发位置与力度

| 项 | 共识 |
|----|------|
| **默认位置** | 钉在**受击高度档**附近（头 / 胸 / 腿等），不是死钉红绿框相交中心 |
| **力度** | 跟随现有**轻 / 中 / 重**招式分档；**共用一套配方 + 力度缩放**（数量、大小、亮度、寿命等强度量） |
| **顿帧关系** | 特效按**自己的时间轴**走；与命中顿帧**分开调节**，不在共识里写死「特效必须跟顿帧一起停」或「必须继续」某一种——编辑/配置能分别控制 |

### 3.5 分组与时间

| 项 | 共识 |
|----|------|
| **分组** | 多个元素可编成一组：有组名；**新建空组**、重命名、删除（含组内元素）、拖拽换组、**整组开关**成立；本轮**不要求**分组复制粘贴 |
| **齐步规则** | 同组共用一个**开始时刻**；组内各元素用**各自寿命与参数**消亡与表现 |

### 3.6 独立特效编辑页（编辑系统）

| 项 | 共识 |
|----|------|
| **形态** | **独立 URL 编辑页**（如 `/hit-vfx.html`），不依赖主训练场对打即可调；**保留训练场场地与光照**，**不加载对战角色** |
| **被照体** | 页内须有**可被照亮的简单物体**（假人块），不能只有虚空击中点 |
| **布局** | **三栏专业 UI（中文）**：左为 **配方 → 分组 → 元素** 树；中为 3D 预览与播放控件；右为当前选中对象的参数检查器 |
| **必须能力** | 配方/分组/元素的新建、重命名、删除（确认）；配方与元素的复制粘贴；调各元素专属参数；元素存为预设并可套用到任意组；**低速 / 逐帧**查看；**一键重放**；**锁定随机种子**；**专用编辑 UI**（非主场景临时叠层） |
| **配方存档** | 存进**项目配置**（与现有预设类似，可进仓库），下次启动可加载；与主训练场命中触发共用同一配方运行时数据 |

### 3.7 算不算必须做成

- **算。** 写进本文件的元素、底座规则、预览台能力与存档，就是要实现的完整目标。  
- 允许规则做简化近似；**不允许**用一段预制逐帧动画、不可调写死特效、或「只有火花没有编辑台」冒充已做成。

## 4. 不做什么（✅）

| 不做 | 说明 |
|------|------|
| 音效 | 打击声等不在本文件 |
| 镜头震动 / 镜头推近 | 相机反馈不在本文件 |
| 角色闪白、受击材质变色 | 不改角色本身材质闪白作为本特效目标 |
| 扣血数字、UI 爆点 | 界面层不在本文件 |
| 布料 / 头发被打飞 | 衣物附属物理不在本文件 |
| 飞行道具本体、大招全屏等 | 非「打中人」特效，不在本文件交付 |
| 整段逐帧精灵作主特效 | 禁止作为主路径 |
| 录好短视频贴击中点 | 禁止作为主路径 |
| 完全不可调的写死特效 | 禁止；必须可编辑 |
| 抄解包官方特效资源 | 禁止作为做法 |
| 每招手搓不可复用整套 | 禁止；必须是可组合元素底座 |
| 粒子碰地弹开/摊开 | 本文件明确：**只靠寿命消失** |
| 体表常驻湿润贴图系统 | 本文件汗水仅飞溅粒子；体表湿润遮罩属美术另案 |
| 把调查文档里的库/算法当已定案 | 技术选型以另立执行方案为准；调查仅供参考 |

## 5. 验收时怎么看（✅）

| 项 | 怎样算过 |
|----|----------|
| **未格挡打中** | 隆训练场 Dummy 不防挨打：可见火花、附带粒子、短促扬尘、汗珠飞溅；火花短暂照亮角色与同组特效；轻重档有可感强度差 |
| **格挡打中** | 格挡成功时走**另一配方**（或可配置为不同配方）仍能触发；与未格挡可以长得完全不同，但须同源底座 |
| **非预制** | 锁种子重放一致；解锁种子多次触发有轻微差异；改参数后外观明显变化——不是播死动画 |
| **独立编辑页** | 打开独立 URL：无对战角色、有场地与光照、有可被照亮假人；加删元素、分组、改参、低速/逐帧、一键重放、锁种子、保存加载配方 |
| **时间轴** | 能证明特效时间与命中顿帧可分开配置/观察（例如顿帧开或关时特效仍可按自己的寿命走，或按配置联动——以可调为准） |
| **存档** | 配方写入项目配置后，重开工程仍能加载同一套 |
| **位置** | 头/胸/腿等受击高度档切换时，特效出现位置跟着变 |
| **不做清单** | 无音效/震屏/闪白/UI 爆点/衣物物理被误当成「特效已完成」的替代品 |
