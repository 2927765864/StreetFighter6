## 1. 一句话（✅）

在桌面 Chrome 的训练场里：光要尽量像街霸 6 训练场；开发者用一套**长期保留的灯光工具**（列表增删、面板改参、场景里看得见并可拖）把光调出来、存进预设；默认方案从旧固定灯迁移，观感先接住再对照截图精修。做成没做成，**工具能力**与**对原作截图的光对照**都要过。

---

## 2. 要做什么（✅）

### 2.1 观感目标

- 光要从训练场该亮的方向来；亮暗和人身上的明暗尽量像原作训练场。
- 不是「随便打亮能看见人」就算完。
- 「像不像」以**街霸 6 训练模式截图**为准，不是「自己看着舒服」。

### 2.2 工具定位

- **使用者**：作者本人 / 开发调试。做成项目里**长期灯光工具**，不是给普通玩家的玩法选项。
- 正式对打画面**不依赖**灯的手柄、辅助线等调试可视物；调试层可关。

### 2.3 灯光数据与编辑能力

- 光源为**可增删的列表实体**，不再以旧扁平字段（如 `lightKeyX` / `lightFill*` / `lightRim*` 等固定五灯槽）作为主路径。
- **完全替换**旧固定 ambient / hemi / key / fill / rim 配置结构；开机默认灯光方案须**迁移成替换前那一套观感**，避免一换系统画面无故「换脸」。
- 支持灯种：**方向光、点光、聚光、环境光、半球光**。
- 可单独调节的灯大约 **8～15** 盏量级（环境光 / 半球光作全局项，通常各 0～1 盏，不占满创意灯名额）。
- 每灯至少可调：开关、颜色、强度、与类型相应的空间参数（位置；方向光/聚光的朝向或目标等）。
- **参数面板「打光」分类**：光源列表（增删、选中）+ 选中项属性。
- **3D 场景**：调试开启时灯**显性可见**（helper / 等价可视），并能用变换手柄**拖位置**（及方向光朝向/目标）。

### 2.4 摆灯时的镜头

- 打光调试允许**临时自由转视角**（摆灯模式），便于绕场看灯、拖灯。
- 退出后回到**平时对打镜头**；自由视角**不改**对打逻辑站位与判定。

### 2.5 阴影

- 第一版要**基础阴影**。
- **仅 1 盏主方向光**负责投影；其它灯只照明、不投阴影（避免多阴影图拖垮性能与调参复杂度）。

### 2.6 存档

- 与现有运行时参数面板一致：进**本地默认 / shipping 预设**体系，重开仍在。
- 灯光方案是可持久化配置的一部分，不是仅内存里临时改改。

### 2.7 算不算必须做成

- **算。** 写进本文件的观感目标与工具能力，就是要实现的完整目标，不是可有可无的装饰。
- 允许缺资源时用看得见的占位推进别的系统；**不允许**用「随便三盏亮灯」或「只有数字滑条、场景里看不见拖不动」冒充光照已做成。

## 3. 不做什么（✅）

| 不做 | 说明 |
|------|------|
| 给玩家开放的灯光菜单 / 训练模式玩法项 | 本文件是开发工具 + 出货观感，不是玩家调光 |
| 多盏灯同时投阴影 | 第一版点名只要单主方向光阴影 |
| 无上限狂加动态灯 | 以约 8～15 盏为量级；不为「越多越好」牺牲稳定 |
| 专业级完整 DCC 编辑器 | 不做完整撤销栈、复杂场景层级树、GI/多弹跳等（未点名即不做） |
| 用占位光冒充「已像原作」 | 对照截图前不得宣称观感做成 |
| 把调查案例里的灯位/架构抄成「已共识的灯坐标」 | 案例只在调查笔记；具体数以对照后另记为准 |
| 公开分发或冒充官方光照授权 | 与主共识法务一致 |

## 5. 怎样算做成（✅）

须**两道都过**，缺一不可。

### 5.1 工具能力

1. 能打开打光工具：列表增删/选中灯，改颜色与强度等。  
2. 调试开启时场景里能看到当前灯，并能拖位置（方向光还能调朝向或目标）。  
3. 可进/出摆灯用自由视角，不影响正常对打镜头与逻辑。  
4. 默认方案观感**接近替换前**的训练场光；能写入本地/shipping 预设并重载恢复。  
5. 存在一盏主方向光投下**基础阴影**；总灯数在约 8～15 盏量级内可调。  
6. 旧扁平灯光字段**不再是主路径**（由灯光列表方案取代）。

### 5.2 观感对照

对照方式：**对着街霸 6 训练模式截图比**，不是「自己看着像就算」。

至少要能对上下面这些站位（左右对调各做一次也算同一套）：

- 两人站在场中间、距离平常  
- 两人拉开到较远  
- 有人贴在左边或右边角落  

每一组要比：

- 光：亮的方向、人身上哪边亮哪边暗、场子会不会过曝或死黑  

**观感已做成** 只在上述对照做过、并且**人写下已对照通过**之后才算。没对照过，不得写成已做成。

网上帖子、别人工程、调查笔记里的数字或截图，**都不能**单独当成已做成的证据。

## 7. 尚未形成共识（⬜）

这些不影响「要做成什么样」，具体数或交互细则对照/实现时再定，**不写进本文件当结论**：

- 默认方案里每一盏灯的精确坐标、颜色 hex、强度数字  
- 聚光锥角、点光衰减等类型专有参数的默认值表  
- 摆灯自由视角的具体键位 / UI 开关文案  
- WebGPU 动态增删灯的引擎开关名称与版本绑定（实现时验证，必要时另记 ADR）  
- 雾、背景色是否仍归「打光」面板同一存档块（可跟实现，未点名强制）

对照或实现完成后，若要把某一条写成共识，再改本文件。
