## 1. 一句话（✅）

隆现有头巾保持造型长度；**额头绑住部分固定**，**脑后飘带**用物理做出比较跟手的甩尾与回弹，跟随移动、跳跃与出招；静止时有轻微呼吸感；手感偏硬、偏短、少挡脸；尽量少钻进头肩；**受击定住与受击硬直期间飘带仍继续动**；参数在调试面板可调，并保存进配置。

---

## 2. 现状前提（✅）

| 项 | 共识 |
|----|------|
| **当前形态** | 头巾是贴在头上的**静态装饰**，不是已有独立飘带动画件 |
| **造型长度** | **先按现有模型长度**，不特意加长或改成围巾级长带 |
| **可动区** | **只有脑后飘带**动；额头绑住部分**不动** |

## 3. 要做什么（✅）

### 3.1 观感目标

- 目标是**比较跟手的物理飘带**：急停、变向、起跳、落地时有明显甩尾与回弹，不是「几乎看不出在动」。
- 手感偏好：**宁可硬一点、短一点**——少乱飞、少挡脸、少出戏；不够飘可以再拧参数，乱飞不可接受为默认。
- 站立不动时要有**一点呼吸感**微晃，避免完全僵死；不要做成抢戏的大风。

### 3.2 动作跟随优先级

第一版都要有反馈，但落地顺序为：

1. **移动**：跑、急停、变向  
2. **跳跃**：起跳、滞空、落地  
3. **攻击**：出招、收招（也要有，但移动与跳跃先保证合格）

### 3.3 时间豁免（不受卡顿拖死）

| 情况 | 共识 |
|------|------|
| **受击定住**（命中卡顿、角色身体定住的那一瞬） | 头巾**继续飘**，不跟身体一起冻住 |
| **受击硬直**（被打后不能操作的那段） | 头巾**整段继续动** |
| **慢动作 / 暂停 / 回放** | ⬜ 尚未形成共识（第一版可不做特殊策略，待另定） |

### 3.4 防穿模

- 观感要**比较干净，少穿模**。
- 碰撞范围：**主要跟角色自己的身体**（头、肩、背等）防穿；**不管场景**（地面、墙壁、道具第一版不做）。

### 3.5 调节与存档

- 要能拧出手感：至少覆盖软硬、回弹、重力感、呼吸晃动一类可感参数（具体字段名属实现，不在本共识钉死）。
- **调试面板**提供实时调节。
- 调好后能**保存成配置**，下次启动仍在（与现有本地默认 / shipping 预设习惯一致）。

### 3.6 算不算必须做成

- **算。** 写进本文件的观感、豁免、防穿模与可调可存，就是要实现的完整目标，不是可有可无的装饰。
- 允许第一版用看得见的简化碰撞或简化链结构推进；**不允许**用「整条头巾跟着头骨转一下」或「完全冻在受击定住里」冒充已做成。

## 4. 不做什么（✅）

| 不做 | 说明 |
|------|------|
| 加长/重做头巾造型 | 第一版不改成长飘带或戏剧化围巾 |
| 额头绑带参与大变形 | 绑住部分保持固定 |
| 其他角色飘带/衣角 | 只做隆 |
| 通用布料引擎全家桶 | 不为「以后所有布料」先铺大系统；本版只服务隆头巾目标 |
| 场景碰撞（地/墙等） | 第一版不做 |
| 以软飘、大甩为默认 | 默认偏硬偏短；夸张飘法若需要，用参数拧，不当默认成功标准 |
| 把调查文档里的算法当已定案 | 技术选型以另立执行方案为准；调查仅供参考 |

---

## 5. 验收时怎么看（✅）

| 项 | 怎样算过 |
|----|----------|
| **移动** | 跑、急停、变向时脑后带有可见甩尾与回弹，且不明显钻头肩 |
| **跳跃** | 起跳、滞空、落地有可见物理反馈 |
| **攻击** | 出招/收招有跟随甩动（标准可略宽于移动/跳跃） |
| **静止** | 有轻微呼吸感，不僵死、不抢戏 |
| **受击定住** | 身体定住时飘带仍在动 |
| **受击硬直** | 硬直全程飘带仍在动 |
| **造型** | 仍是现有长度；额头固定、脑后动 |
| **手感默认** | 偏硬、偏短、少挡脸；可用面板拧 |
| **存档** | 面板改参后能保存，重开仍在 |
| **范围** | 仅隆；场景碰撞未做不算失败 |
