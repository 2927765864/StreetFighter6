# 记法约定

> 本地表、调试 HUD、文档统一使用下列记法（面朝右；面朝左时左右对调）。

---

## 1. 方向（Numpad）

```
7 8 9
4 5 6
1 2 3
```

| 数字 | 含义 |
|------|------|
| 5 | 中立 |
| 6 / 4 | 前 / 后 |
| 2 | 下 |
| 8 | 上 |
| 3 / 1 / 9 / 7 | 斜向 |
| 236 | 下→下前→前（QCF） |
| 214 | 下→下后→后（QCB） |
| 623 | 前→下→下前（DP） |
| 22 | 下下 |
| 66 / 44 | 前冲 / 后撤 |

---

## 2. 按钮

| 记法 | 含义 |
|------|------|
| LP MP HP | 轻 / 中 / 重拳 |
| LK MK HK | 轻 / 中 / 重脚 |
| P / K | 任意拳 / 任意脚（强度由上下文） |
| PP / KK | 同系两键（OD） |
| 5LP | 站立轻拳 |
| 2MK | 蹲中脚 |
| j.HP | 空中重拳 |
| 6MP | 前 + 中拳（指令普攻） |

---

## 3. 连段 / 取消

| 记法 | 含义 |
|------|------|
| `A > B` | **Cancel**：A 动画未完进入 B |
| `A ~ B` | **Target Combo / 指定 chain** |
| `A , B` | **Link**：A 完整 recovery 后再出 B |

---

## 4. Cancel 标志（公开表常见）

| 标记 | 含义 |
|------|------|
| C | 可 cancel 进 special、DI、DR、Super 等（以官方/社区图例为准） |
| Sp | Special |
| SA / SA2 / SA3 | 对应等级 Super |
| Chn | Light chain 等 |
| TC | Target Combo |
| Jmp | Jump cancel |

本地 JSON 可用英文字段表达同等语义，见 `schema-move-table.md`。
