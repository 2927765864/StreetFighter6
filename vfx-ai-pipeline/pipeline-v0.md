# 完整管线 v0（管线 C · 生成端 A）

> **上位**：`consensus-v0.md`  
> **生成契约**：`generation-contract-v0.md`  
> **本命中实例拆解**：`_analysis/完整命中特效参考.decomposition.md`  
> **生成端**：Agent 内置 `image_gen` / `image_edit` + 本地确定性后处理（不依赖本机 ComfyUI）

---

## 0. 管线一览

```text
① 参考视频入仓
② 抽帧分析 → 组成元素拆解文档
③ 按元素写/套生成契约 Prompt
④ image_gen 出 raw 2×2 sheet
⑤ 质检 raw（契约清单）
⑥ 确定性后处理：色键 → 切格 → 对齐 → 打包 → preview.gif + meta
⑦ 审查 preview（及必要时单帧）
⑧ 不合格 → 只迭代该元素（改 prompt / image_edit 坏格）→ 回 ④ 或 ⑥
⑨ 合格元素入库；全部元素齐后 → 组合说明（运行时叠层，配方后定）
```

**原子循环单位** = 单一组成元素（E1…E5），不是整段命中。

---

## 1. 阶段说明

### ① 参考入仓

| 项 | 做法 |
|----|------|
| 放置 | 参考视频放在 `vfx-ai-pipeline/` 下（本实例：`完整命中特效参考.mp4`） |
| 要求 | 能看清命中瞬间的分层；过短也可，靠抽帧读相位 |

### ② 分析与拆解

| 项 | 做法 |
|----|------|
| 抽帧 | 足够读相位即可（本实例约 15 fps → `_analysis/frames/`） |
| 产出 | 拆解文档：元素列表 + 每元素风格/运动/效果描述 + 非 sheet 层 |
| 标准 | 只拆「可独立 sheet、可独立叠层」的层；红填/点光/运动模糊写入「非 sheet」 |
| 本实例 | `_analysis/完整命中特效参考.decomposition.md`（v1：E1 闪光 / E2 近核火花 / E3 圆环烟 / E4 宽短冲击烟 / E5 窄长冲击烟；汗不做） |

### ③ 套用生成契约

| 项 | 做法 |
|----|------|
| 文档 | `generation-contract-v0.md` |
| 动作 | 取全局 LAYOUT + CHROMA + 该元素 BODY + FRAMES + AVOID，拼成一条完整 prompt |
| 顺序建议 | E1 → E2 → E3 → E4 → E5（核→火花→环烟→宽短烟→窄长烟） |

### ④ 生成 raw sheet

| 项 | 做法 |
|----|------|
| 工具 | Agent `image_gen`（主）；局部坏格可用 `image_edit` |
| 输入 | §③ 完整 prompt；可选：拆解用关键帧作风格参考（须先在对话中可见） |
| 输出 | `raw-sheet.png`（仍带洋红底的 2×2） |

### ⑤ raw 质检

按契约 §4 清单目视：网格、洋红底、单元素、居中、相位可读。  
失败则 **不要进入后处理**，回 ③/④。

### ⑥ 确定性后处理

模型不再参与「画画」。脚本（或等价步骤）固定执行：

| 步骤 | 行为 |
|------|------|
| 色键 | 去掉 `#FF00FF`（容差可调），得到 alpha；必要时轻微 despill / 去毛边 |
| 切格 | 按 2×2 等分切出 `frame-00` … `frame-03` |
| 对齐 | 按非透明 bbox 估中心，pad 到统一 cell（尺寸执行时再定，默认正方形） |
| 打包 | 透明 `sheet-transparent.png`；可选横条 atlas |
| 预览 | `preview.gif`（按固定帧间隔播放） |
| 元数据 | `pipeline-meta.json`：网格、cell、chroma、anchor、元素 ID、prompt 摘要路径 |

建议单次元素交付目录形态（执行时可再钉路径名）：

```text
runs/<effect_id>/<element_id>/
  prompt-used.txt
  raw-sheet.png
  sheet-transparent.png
  frames/frame-00.png …
  preview.gif
  pipeline-meta.json
```

### ⑦ 审查

| 看什么 | 合格大致标准 |
|--------|----------------|
| `preview.gif` | 相位顺、无跳格、无洋红残留、无串层 |
| 单帧 | 居中稳定、边缘可接受、风格符合拆解 |
| 与参考关系 | **神似分层职责**，不要求像素级复刻官方 |

### ⑧ 迭代

| 问题类型 | 动作 |
|----------|------|
| 相位错 / 串了烟或火 | 改 FRAMES / BODY，整张重生成 |
| 单格坏、其它格好 | `image_edit` 只修该格，或整张重生成 |
| 抠图毛边 / 洋红渣 | 只调后处理容差与 despill，不重画 |
| 已合格元素 | **不动** |

### ⑨ 多元素组成完整特效

| 项 | 做法 |
|----|------|
| 产物 | E1–E5 各一套可交付 sheet |
| 合成 | 运行时/配方按时间叠加（阅读顺序：爆心→火花→环烟→宽短烟→窄长烟） |
| 本管线边界 | **不**在本阶段烘焙成一张最终合成大图才算完成；组合格式后定 |
| 非 sheet 层 | 红填、点光等仍走角色/程序化路径，不混进 AI sheet |

## 2. 角色分工

| 角色 | 负责 | 不负责 |
|------|------|--------|
| 人 | 给参考、审查 preview、裁定合格 | 不必手切图、不必开 Comfy |
| Agent | 拆解、拼 prompt、生成、后处理、按意见迭代、交付文件 | 不把 raw 当成品；不改程序化打击特效主共识 |
| 脚本 | 色键/切格/对齐/GIF/meta | 不做创意决策 |

---

## 3. 与调研结论的对应（为何这样设计）

| 调研点 | 落在本管线 |
|--------|------------|
| 一次生成整网格更易风格一致 | ②→④ 用 2×2 单次出四相位 |
| Image gen ≈ 20%，后处理 ≈ 80% | ⑥ 单独成确定性阶段 |
| 纯色底 + 禁止主体含色键色 | 契约 CHROMA + 洋红 |
| FX 与身体/宽层分离 | 拆解 E1–E5 分 sheet；红填不进 sheet |
| Agent 可交付 | 生成端 A；契约 + 目录形态固定 |
| 少格优先（2×2 / 2×3） | 默认 2×2，命中短寿命够用 |

## 5. 尚未钉死（不阻塞按契约开跑）

- cell 像素边长、GIF 帧间隔具体数值  
- 后处理脚本文件名与依赖安装方式  
- 运行时混合模式 / 配方 JSON 格式  
- 与 `docs/hit-vfx-consensus-v0.md` 程序化底座的挂接接口  

开跑时用契约默认值即可；数值可在第一次后处理落地时写入 `pipeline-meta.json` 并回填本文。
