### E1 运动规律

1. **锚在拳面接触点**，不飞走、不绕圈  
2. **出现即接近峰值**（帧 0→1 一次打满），不是从小圆慢慢长大

## 3. 迭代史与教训

### iter1：一张 prompt 赌 2×2（4 帧）

- **结果**：光滑高斯椭圆光斑，像 Logo  
- **教训**：少帧 + 网格一次生成 → 丢连贯、形态假；命中闪光不是椭圆光晕

### iter2：参考裁切隔离 + 再修

- **结果**：有撕碎感，但仍乱；峰值易变成电弧/星爆  
- **教训**：形态方向对了，但隔离质量不稳

### iter3：按参考帧 1–10 逐帧独立隔离 → 10 帧 / 30fps

- **结果**：帧数对了；**第 3 格相对干净**（主要是 flash）；其它格常混进烟、火花、脏斑；帧间尺寸乱跳  
- **用户反馈（正确理解）**：  
  - 「第三格比较好」= **没有乱七八糟的其它元素**，只保留了 flash  
  - **不是**说让全部照着第三格生成  
- **教训**：  
  - 密度应用 **~10 帧 @30fps**，不要 4 帧  
  - 每帧必须 **只含 E1**，但各帧仍要跟参考该时刻的闪光相位走  
  - 独立隔离容易串层，也容易不连贯

### iter4：误把第 3 格当母版，全部 morph

- **结果**：**更差**——全序列长得像同一张在缩放，丢失参考各相位差异，连贯变成假连贯  
- **教训（硬错误）**：  
  > **「干净」≠「当母版复制」。**  
  > 好格的标准是「元素纯净」；其它帧应对照参考**对应时刻**的闪光，各自干净地生成/隔离，再用手段保证连贯，而不是克隆第 3 格。

## 4. 下轮迭代应怎么做（建议）

### 要做

1. 继续 **10 帧（对齐参考 1–10）@30fps**，5×2 或横条均可  
2. **每帧对照参考该帧裁切**（`_analysis/e1_motion/crop_01.png` … `crop_10.png`）  
3. 隔离时硬约束：**只保留核心闪光**；明确禁止烟、火花、碎屑、汗、角色  
4. 用第 3 格当 **「干净度标杆」**（检查清单），不当形状母版  
5. 连贯性：同一锚点、同一色温家族、共享缩放、相位单调衰减；必要时 **顺序编辑**（上一帧 → 下一帧只改尺寸/碎条），而不是「全克隆第 3 帧」  
6. 每轮交付：`raw-sheet` / `sheet-transparent` / `frames/*` / `preview.gif@30fps` / 对照说明  

### 不要做

1. 不要再压成 2×2 四帧当最终 E1  
2. 不要把认可的干净格当成全序列唯一母版去 morph  
3. 不要在 E1 里混 E2/E3/E4/E5  
4. 不要假设片源是 60fps 几十帧（本文件是 30fps / 17 帧）

### 验收口语（用户侧）

- 每一格都像「只有 flash」，像第 3 格那么干净  
- 播 `preview.gif` 时能看出 **同一团横向撕碎光在收**，而不是十张不相关贴纸  
- 对照 `contact_strip.png` / 参考视频，相位大致对齐帧 1–10

## 7. 一句话总结

**帧数要对（~10@30fps），每帧要干净（只 flash），帧间要连贯（同一团光在变）——三者缺一不可；「干净样例」用来验纯净，不能用来克隆全序列。**
