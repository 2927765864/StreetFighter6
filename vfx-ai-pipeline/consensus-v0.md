## 1. 一句话（✅）

从参考特效视频出发，把完整特效拆成可独立叠层的组成元素；为每个元素写清风格与运动变化，再按生成契约单独生成一张 sheet，经切分、抠图、打包得到预览并审查迭代；完整特效由多张元素 sheet 组合而成。生成端由 Agent 使用内置图像工具产出，本地用确定性步骤做成可交付素材。

## 2. 管线形态（✅）

| 项 | 共识 |
|----|------|
| **选定形态** | **管线 C**：用 prompt（及必要的布局/参考约束）生成 sheet → 切分 → 抠图 → 打包 → `preview` 审查 → 迭代 |
| **生成端** | **方案 A**：Agent 内置图像生成/编辑 + **本地确定性后处理**；**不依赖**使用者本机 ComfyUI |
| **操作主体** | 在约定契约内，Agent 应能独立完成拆解、描述、生成、后处理、预览与按审查意见迭代，直到该元素可交付 |
| **原子交付物** | **单一组成元素**的一张 sheet（及由其得到的帧、预览与元数据） |
| **完整特效** | **多张**元素 sheet 在运行时/配方中的叠加组合，不是「整段参考压成一张 sheet」 |

## 3. 要做什么（✅）

### 3.1 组成元素拆解

| 项 | 共识 |
|----|------|
| **拆解目标** | 回答参考视频里有哪些**可分离、可独立生成与叠层**的视觉组成元素 |
| **拆的标准** | 能单独成一张 sheet；能单独调时序、混合、缩放等，再与其它层合成 |
| **典型元素（举例，非穷尽清单）** | 核心闪光、冲击波环、火花、烟雾、刀光弧、残影、落地点尘等 |
| **粒度** | 按可独立叠层的层拆；同层内分不开的微结构不必硬拆 |

### 3.2 逐元素描述

| 项 | 共识 |
|----|------|
| **每个元素一份说明** | 外观风格、运动方式、生命周期变化（出现→峰值→消散）、透明度/亮度或形态变化、大致帧相位 |
| **用途** | 作为该元素生成契约与 prompt 的输入；描述本身不是最终美术成品 |

### 3.3 逐元素生成与后处理

| 项 | 共识 |
|----|------|
| **一次一个元素** | 每个组成元素单独进入：描述 → 契约约束下生成 sheet → 切分 → 抠图 → 打包 → 预览 |
| **生成** | 以 prompt 限定布局与内容（必要时加布局/参考约束）一次生成该元素的 sheet |
| **后处理** | 切分、抠图、对齐、打包为**确定性**步骤；模型负责出图，脚本负责变成可用素材 |
| **预览** | 必须给出可审查的运动预览（如 `preview.gif`） |
| **迭代** | 审查后只改不合格元素的描述/prompt 并重跑该元素；已合格元素不动 |

### 3.4 合成关系

| 项 | 共识 |
|----|------|
| **合成含义** | 完整特效 = 多张元素 sheet 在时间与渲染层上的组合 |
| **本管线当前交付** | 分层元素素材 + 预览 + 元数据；**不要求**把所有层烘焙成一张最终大图才算完成 |
| **组合细节** | 各 sheet 的先后、混合模式、缩放跟随等属配方/运行时，**当前不钉死** |

## 4. 不要做什么（✅）

| 项 | 共识 |
|----|------|
| **整段单 sheet 冒充完整特效** | 不以「整段参考视频只出一张 sheet」作为完整特效的唯一产物 |
| **糊层 / 乱拆** | 不把生命周期与叠层方式明显不同的层画在同一元素 sheet 里；也不把无法独立叠层的微结构硬拆成多个元素 |
| **接管程序化运行时** | 不负责发射器、物理、点光、与 hitstop 时钟关系等程序化特效系统本身 |
| **后处理再生成** | 不以「再让模型画画」代替切分、色键、对齐、打包 |
| **生图即成品** | raw sheet 不是可交付成品；须过后处理与 QC |
| **本文件锁死执行细节** | 不在本共识里规定目录细目、格像素、具体色值、脚本名、引擎挂接代码 |

---

## 5. 怎样算做成（✅）

就**某一个组成元素**而言，同时满足下列条件即视为该元素在本管线下可交付：

| 项 | 共识 |
|----|------|
| **有拆解依据** | 能指出它对应参考中的哪一类可分离组成 |
| **有文字描述** | 风格与运动/变化说明已写清，并作为生成输入 |
| **有 sheet 产物** | 在契约约束下生成，并完成切分、抠图、打包 |
| **有预览** | 有可审查的运动预览 |
| **通过审查** | 经审查认可，或按意见迭代至认可 |

就**某一完整参考特效**而言：其列出的各组成元素均按上表可交付；元素之间的运行时组合方式可以后定，不阻塞元素交付。
