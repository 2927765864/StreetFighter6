# E1 对照（iter8）

## 用户纠正

iter7 把位移做成**往回收（向左）**，方向反了。参考是闪光随打击/击退**向右带走**，同时**溶解消失**，不是缩回拳面。

「向后」= 受击者被打退的方向 = 本片从左向右。

## iter8

| 项 | 做法 |
|----|------|
| 位移 | 拳面左缘为出生锚，整团 **+x（向右）** 轻移：0→70px |
| 消散 | 边缘先蚀、噪声斑、alpha 变透、余光仍偏白金；右向能量拖尾 |
| 禁止 | 居中缩放、右舌收回、向左收 |

## 对照 sheet

上排已能读出**越来越靠右**；下排同形变淡，不是往左缩。

## 仍差于参考

- 溶解仍偏「同一剪影变透明」，参考中段更像多层火条自己散开、碎掉。
- 后段在黑底上偏灰，参考残核仍有短金条。
- 形态仍是实心三叉家族。
