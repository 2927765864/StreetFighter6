# E1 对照（iter9）

## 纠正

iter8 的「溶解」= 同一剪影 alpha 变淡。用户明确说**不是透明度渐隐**。

参考实际结构：

| 阶段 | 参考 |
|------|------|
| 峰值 | 一团叠层白核 |
| 中段 | **沿纹理裂开**成几条横向金白火带，条与条之间有缝 |
| 后段 | 火带再撕成短条，碎块仍亮 |
| 将熄 | 剩一两截短条，不是原剪影的幽灵 |

## iter9 相位

1–2 整团 → 3–4 裂成三舌缝 → 5–6 碎成条带 → 7–10 两条残核+向右碎屑；整团仍向右带走。

## 仍差

- 碎屑偏金箔片，参考更像光带自己散开。
- 末格两条还偏完整。
- 裂开跳变略猛（格 2→3）。
