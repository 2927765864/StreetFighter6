# E3 对照（iter5）不规则裹圈 — 运动沿用 iter4

14 帧 @30fps，7×2，固定画幅。扩环+渐隐保留；换掉正圆缩放纹理。

## 用户反馈（iter4）

运动正常，但观感是「规整圆环在缩放」，不规则头肩裹圈不够。

## iter5 改法

- 从参考隔离 C 形 / 马蹄裹圈 / 碎团蒸汽（`iter5_seq/`），禁止正圆、花环、描边圈。
- 丢掉带人形剪影、气泡的失败格。
- 前段碎裹圈 → 中段底缺口马蹄 → 后段更碎更淡，同时半径单调变大、alpha 下降。

- 前 3 格太碎、太小，参考峰值时烟量更大。
- 中段马蹄仍略对称，参考右肩更鼓。
- 品红毛边在半透明格上仍可见。

## 用户指出的问题（iter3）

1. 观感差：前段像实心棉花团，太实。
2. 透明度/淡度不对：环烟应是**较淡的蒸汽**，不是厚白云。
3. **缺少向四周扩散、渐隐渐淡、渐渐消失**。原因：每格按自身 bbox 居中缩放，半径变化被吃掉。

## iter4 改法

- 重新生成淡灰白半透明蒸汽环（`iter4_seq/`）。
- 打包：**同一相机、整格画布**；半径从约 22px 单调增到约 127px；alpha 从约 0.78 降到约 0.05。
- 前 8 格同一团淡环纹理扩开变淡；后段接到更薄的残弧再消失。

## 对照循环做了什么

1. **iter1 隔离**（crop_01/03/05/08/11）：模型把环读成**正圆花环/几何细线**，和参考「贴头肩的不规则蒸汽裹圈」差得远。
2. **iter2 改提示词**：强调 C 形、头顶和右肩更密、底侧断开、禁止 doughnut。crop_03 / 紧 C 形出生可用；crop_08 色键反了；crop_11 仍串角色或变成线稿。
3. **iter3**：用合格锚点做半径变大、壁变薄的顺序编辑，丢掉失败的几何环和角色残图，打包 14 帧。

## 相位对照

| 格 | 参考 | 本轮 |
|----|------|------|
| 0–1 | crop_01 紧贴头肩的白烟裹圈 | C 形空心蒸汽，上右更厚，左下断开。接近职责，略糊、略厚 |
| 2–4 | crop_03 头肩半径胀一圈 | 不规则空心裹圈，底缺口。形态对，略像积雨云、不够蒸汽薄 |
| 5–8 | crop_05–08 半径更大、更透 | 马蹄形薄晕，壁更细。读得出扩环，但变成更「冲击波马蹄」，体积团块少了 |
| 9–13 | crop_09–12 残弧 | 淡上弧→几乎空。方向对；中间一格几乎空得太早，残雾比参考更弱 |

## 干净度

无角色、无 E1 闪光、无 E2 火花、无 E4/E5 长条平移烟。单元素成立。

## 相对参考仍明显不一致（下一轮优先）

1. **半径增长不够单调**：bbox 共享缩放后，前段 C 形和中段裹圈视觉半径跳变，不像参考那样一圈圈胀开。
2. **风格两截**：前段团块蒸汽 ↔ 后段平滑马蹄晕，不是同一团烟在变薄。
3. **正圆/马蹄感仍偏多**：参考是裹在头肩轮廓上的碎蒸汽，不是对称 U 形。
4. **色键品红边**：部分格边缘发粉，需再降容差或 despill。
5. **残环**：参考墙面是淡而宽的弧，本轮后期过细、过短。
