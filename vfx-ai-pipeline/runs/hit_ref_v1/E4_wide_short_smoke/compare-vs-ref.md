# E4 对照（iter3 平移打包）

14 帧 @30fps，7×2，cell 256。固定画幅（不按 bbox 撑满）。

## 对照循环做了什么

1. **iter1 隔离**（crop_01/03/05/08）：模型读成 **3D 积雨云 / 棉花团**；crop05 还拖出彗星尾（串成 E5）。和参考「被拳头推走的扁短蒸汽块」差得远。
2. **iter2 改提示词**：强调扁短板、撕边、2D 格斗特效蒸汽、禁止积雨云。crop03 可用；crop05 质心已在右侧（运动对）；crop08 失败（训练场墙 + 文字）。
3. **iter3**：用合格扁短团做出生 / 右移 / 残雾，再用脚本按固定相机做 **质心左→右平移 + 渐隐**，14 帧。丢掉打孔瑞士奶酪和带尾的格。

## 干净度

无角色、无 E1 闪光、无 E2 火花、无 E3 圆环扩层、无 E5 细长带。单元素成立。

## 相对参考仍明显不一致（下一轮优先）

1. **蒸汽感不够**：参考是半透明碎蒸汽，本轮前段偏实心灰云印章。
2. **轮廓更椭圆**：参考贴胸肩、上缘不规则；本轮左右对称扁团。
3. **纹理两截**：出生团（有明暗核）↔ 中段平涂灰斑。
4. **后段略方**：残雾比参考更「一块」，碎开不够。
5. **个别格仍有极淡品红边**（色键后）。

运动阅读已对：**一块宽短烟被沿打击轴推走并变淡**，不是扩环、不是长条。
